📥 Penerimaan Barang (Receiving)
Nomor batch TIDAK dibuat otomatis. Segmen "Jenis" (AA) pada format nomor batch masih [BELUM DIKONFIRMASI] ke PT JAS, jadi generator sengaja belum diimplementasi (lihat BATCH_NUMBER_SPEC.md). Isi nomor batch manual kalau sudah ada dari catatan lain, atau kosongkan — batch tetap tersimpan tanpa nomor.
 
⚖️ Data Berat
Ini yang jadi kuantitas batch — diisi otomatis dari Bruto−Tara, bisa diedit manual.
🔍 On-Spec / Off-Spec (dicatat, tidak memisah batch)
Sesuai keputusan engine (services/receiving.py): seluruh netto tetap jadi satu batch. On-spec/off-spec di sini hanya dicatat sebagai catatan, belum otomatis membuat batch terpisah atau menandai batch ditolak.
⚙️ Input Proses
Satu halaman untuk semua tahap proses yang sudah tersambung. Field angka hasil turunan (rata-rata KA, penyusutan) hanya ditampilkan dari hasil respons API setelah disimpan — tidak dihitung ulang di sisi form supaya aturan bisnis tetap satu-satunya di engine Python.
